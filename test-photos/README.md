# Test photos (street reports)

Small openly licensed photos from Wikimedia Commons used by `scripts/report-demo.ts`
and for manual testing of the "Report a street problem" sheet. None of them has GPS
EXIF, so they exercise the location fallback (device location / address / map pin).
Some were downscaled (800 px, JPEG q80); no other changes.
